# Calibration task for <DOMAIN>

This is an excluded pilot task.

- **R1:** decode_pointer(pointer) in pointer.py returns JSON Pointer segments: empty string means root, other strings must start with '/', empty segments are valid keys, ~0 decodes to '~' and ~1 to '/', and malformed escapes or non-string/fragment pointers raise ValueError; perform no URL decoding.
- **R2:** get_value(document,pointer) in pointer.py traverses dictionaries by literal key and lists by canonical nonnegative decimal index ('0' or a nonzero digit followed by digits); reject missing keys, out-of-range indices, leading zeros, signs, '-' list lookup, or scalar traversal with ValueError, and return a deep copy of the selected JSON value.
- **R3:** apply_basic(document,operation) in __SF_MONITOR_COMPONENT__.py supports add,remove,replace,test without mutation: dictionary add creates or overwrites, list add inserts at index <= length or appends for '-', replace/remove require an existing target, root add/replace returns a deep-copied value and root remove returns None; test uses structural JSON equality with bool distinct from numbers and numeric 1 equal to 1.0, and returns an unchanged deep copy on success; all invalid operations, failed tests, missing required fields, or invalid paths raise ValueError.
- **R4:** apply_move_copy(document,operation) supports move and copy with required from/path pointers: fetch a deep copy of the source first, copy adds it, and move removes source before resolving the destination, so array indices refer to the post-removal document; moving an ancestor into its own descendant is invalid, moving an existing pointer to itself is a no-op, moving a child to root is allowed, and copying an ancestor into a descendant must not create shared references; errors raise ValueError without input mutation.
- **R5:** apply_patch(document,operations) in __SF_MONITOR_COMPONENT__.py applies a list of basic/move/copy operations in order on a deep copy, returns an independent copy for an empty list, and raises ValueError atomically on any invalid operation while leaving both original document and operations unchanged.

Inputs are JSON-compatible objects (string-keyed dictionaries, lists, strings, finite numbers, bool, None). Operation objects use standard keys op,path,value,from; value is required for add,replace,test, and from for move/copy. Root is denoted by ''. An empty-key dictionary member uses '/'. Missing parent containers are errors rather than auto-created. Extra operation keys may be ignored. Pointer parsing and value lookup can be implemented independently of operation application; use two complete replacement files.
